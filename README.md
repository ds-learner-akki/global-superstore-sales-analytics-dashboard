# Global Superstore Sales Analytics Dashboard

Interactive Power BI dashboard built to analyze **sales, profit, customer segments, regional performance, and monthly sales trends** using the Global Superstore dataset.

---

## Project Overview

This project focuses on transforming raw retail sales data into a **business-friendly analytics dashboard** that helps track revenue performance, profit contribution, seasonal trends, and geographic sales distribution.

The dashboard was designed to simulate a **real-world business reporting solution** where decision-makers can monitor KPIs, filter data dynamically, and identify high-performing regions and periods.

---

## Tools & Technologies

* **Power BI Desktop**
* **Power Query**
* **DAX (Data Analysis Expressions)**
* **Excel / CSV Dataset**

---

## Dashboard Features

### KPI Cards

* **Total Sales:** $12.64M
* **Total Profit:** $1.47M

### Visualizations

* **Sales by Year** – Year-over-year revenue comparison
* **Sales by Quarter** – Quarterly sales contribution analysis
* **Sales by Month** – Monthly sales trend across multiple years
* **Sales by Country** – Geographic sales distribution using a map visual

### Interactive Slicers

* Region
* Country
* Segment
* Category
* Region Group

---

## Data Preparation

The dataset was cleaned and transformed using **Power Query**:

* Removed duplicate and unnecessary columns
* Handled null and missing values
* Corrected data types for dates, sales, and profit fields
* Created calculated columns and relationships for reporting
* Prepared the data model for efficient dashboard performance

---

## Key Business Insights

* **2019 recorded the highest annual sales**, showing a steady growth trend compared to previous years.
* **Q4 contributed the largest share of revenue**, indicating strong seasonal performance during the final quarter.
* **North America emerged as the top-performing region** in terms of overall sales contribution.
* Monthly trend analysis showed **consistent sales acceleration during the second half of the year**, with noticeable peaks in **November and December**.
* The dashboard helps identify **high-revenue countries and regional sales concentration**, supporting territory-level performance analysis.
